# 🧩 Pokédex & Team Builder — Full Interactive Pokémon Database

A beautifully designed, fully interactive **Pokédex web application** built with **HTML, CSS, JavaScript, and Bootstrap**.
This project connects directly to the **PokéAPI** and includes advanced features such as **Pokémon search**, **detailed stats**, **evolutions**, **forms**, **weakness analysis**, and even a full **drag-and-drop team builder with team comparison**.

---

## 🚀 Features

### 🔍 **1. Search Any Pokémon**

* Search by **name or Pokédex ID**
* Displays official artwork
* Error handling for invalid entries

### 📄 **2. Detailed Pokémon Information**

Includes:

* Height & Weight
* Typing
* Moves (full move list)
* Base Stats
* Shiny Form preview
* Evolutions (auto-fetched recursively)
* Weakness chart (based on typing)

### 🔄 **3. Full Forms & Variants System**

Automatically detects and displays:

* Regional forms (Alola, Galar, Hisui, Paldea)
* Mega Evolutions
* Primal Reversions
* Gigantamax forms
* All alternate species varieties

### 🧪 **4. Drag-and-Drop Team Builder**

Create two separate teams with:

* 6-Pokémon limit
* Duplicate prevention
* Type badges
* BST (Base Stat Total) auto-calculation
* Removable team slots
* Clean drag-and-drop animations

### ⚔️ **5. Team Comparison Engine**

Compare **Team 1** and **Team 2** by:

* Total BST
* Average BST
* Auto-declares which team is stronger

### 🎨 **6. Modern UI / UX Design**

* Custom themed Pokédex layout
* Responsive design
* Bootstrap icon support
* Smooth animations
* Clean card-style Pokémon list
* Custom scrollbars

---

## 🛠️ Technologies Used

* **HTML5**
* **CSS3** (custom, including animations & responsive layout)
* **JavaScript (Vanilla)**
* **Bootstrap 5**
* **PokéAPI**
* **PogoAPI** (Mega Evolution data)

```

script.js         → Pokédex core logic
compare-pokemon.js→ Team comparison logic
Main-Components.js→ Additional page functionality
```

## 📦 Installation & Usage

1. Download or clone the repository:

```bash
git clone https://github.com/your-username/pokedex-team-builder.git
```

2. Open `index.html` in any browser.

No backend required!
